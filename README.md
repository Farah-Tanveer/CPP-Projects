# CPP Projects

Welcome to the CPP Projects repository! This repository contains a collection of various C++ projects aimed at demonstrating different programming techniques and algorithms.

## Projects Overview

1. **Project 1: Hello World**  
   A simple "Hello, World!" program that introduces the basic syntax of C++.

2. **Project 2: Sorting Algorithms**  
   Implementations of various sorting algorithms including Bubble Sort, Quick Sort, and Merge Sort.

3. **Project 3: Simple Calculator**  
   A command-line calculator that can perform basic arithmetic operations like addition, subtraction, multiplication, and division.

4. **Project 4: File I/O Operations**  
   Demonstrates how to read from and write to files in C++.

5. **Project 5: Basic Data Structures**  
   Implementation of basic data structures such as Linked Lists, Stacks, and Queues.

## How to Use

1. Clone the repository using the command:  
   `git clone https://github.com/Farah-Tanveer/CPP-Projects.git`

2. Navigate to the project directory:  
   `cd CPP-Projects`

3. Compile the C++ files using a C++ compiler (like g++):  
   `g++ -o output_file_name filename.cpp`

4. Run the compiled program:  
   `./output_file_name`
